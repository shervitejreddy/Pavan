# Gopool Hyderabad - IT Campus Ride Share & Green Commute Benefit (Angular)

Gopool is an Angular 19 web application for Hyderabad tech corridor commuters across HITEC City, Financial District, Knowledge City, and Gachibowli. It connects verified IT employees to share bike and car rides, split fuel costs equitably, and disburse corporate green subsidies (₹3 for bike pools, ₹5 for car pools).

## Features Ported to Angular

- **Interactive Corridor Map**: Real-time Google Maps Platform integration displaying Hyderabad commute radar across 30+ areas, pickup points, tech campus destinations, and live telemetry tracking.
- **Fair Fuel Cost Splitter**: Non-commercial fuel expense sharing calculator for bikes and cars (Petrol, EV, Diesel) accounting for corporate green subsidies.
- **Corporate Green Commute Benefit**: Personal Green Wallet accumulating ₹3 (bike) and ₹5 (car) subsidies, direct redemption vouchers (Campus Cafeteria, HPCL/IOCL Fuel, Payroll), and corporate ESG metrics.
- **Corporate HR Verification Portal**: Digital employee badge pass authentication, zero-stranger policy, and an HR admin console for reviewing employee requests.
- **Live Ride Simulator**: 4-step commute simulation with GPS corridor routing, safety/helmet verification, campus RFID gate arrival, and automated subsidy disbursement.
- **Ride Scheduling & Booking**: Modals to offer rides, select pickup points, calculate fair shares, and reserve pillion or carpool seats.
- **Demo Identity Switcher**: Switch between verified IT employee personas from Microsoft, Google, TCS, Wipro, Amazon, and Infosys.

## Tech Stack

- **Framework**: Angular 19 (Standalone Components, Signals & Reactive Change Detection)
- **Styling**: Tailwind CSS v4 + PostCSS
- **Maps**: Google Maps JavaScript API (MarkerElement, Polyline, InfoWindow)
- **Tooling**: Angular CLI (`@angular/build`, `@angular/cli`)
